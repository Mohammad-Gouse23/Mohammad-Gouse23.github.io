## Publish with GitHub Pages

### Option A — use a personal site repository

1. Sign in to GitHub.
2. Create a **public** repository named exactly `Mohammad-Gouse23.github.io` (use your GitHub username).
3. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root. Do not upload the ZIP itself as the only file.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait a few minutes. Your site should be available at `https://Mohammad-Gouse23.github.io`.

### Option B — use an existing repository

1. Upload the three website files to the repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The URL will usually be `https://Mohammad-Gouse23.github.io/REPOSITORY-NAME/`.

## Update the portfolio

Edit `index.html` for text and links. Edit `styles.css` for colors, spacing and layout. Edit `script.js` for small interactions. Commit and push the changes; GitHub Pages republishes the site automatically.
